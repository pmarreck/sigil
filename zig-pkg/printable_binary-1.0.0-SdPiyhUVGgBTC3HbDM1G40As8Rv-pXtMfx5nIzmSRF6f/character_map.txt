## PrintableBinary character map — SOURCE OF TRUTH for every implementation
## (Zig @embedFile, C via utils/generate_embedded_map.lua, Lua CLI, JS).
##
## Format: one glyph per line, in byte order. Line N (after filtering comments)
## is the glyph for byte N. Exactly 256 glyph lines. The glyph is the FIRST
## whitespace-delimited token on the line.
##
## ASCII passthrough (the core point): letters (A–Z, a–z), digits (0–9), and
## . @ ^ _ map to THEMSELVES — 66 of the 94 printable non-space bytes — so ASCII
## text stays legible in the encoded form even when mixed with control/high bytes.
## The other printable bytes take look-alike glyphs to stay unambiguous: 0x20
## space -> ␣, plus the 28 punctuation ! " # $ % & ' ( ) * + , - / : ; < = > ? [ \ ] ` { | } ~
## (see per-line trailing notes). Byte 0x23 '#' -> ♯ is discussed below.
##
## Comments:
##   - A line beginning with `##` (two or more '#') is a full-line comment, skipped.
##   - A trailing `<glyph> ## comment` is ignored (only the first token is taken).
##   - `##` (not a single '#') is the marker on purpose, so a lone '#' can be a
##     glyph someday without ambiguity. Today byte 0x23 ('#') maps to ♯, not '#'.
##
## Space (byte 0x20 -> ␣ U+2423, 3 bytes): kept 3-byte ON PURPOSE. No 2-byte glyph
## works — the disqualifier is East Asian Width = Ambiguous, which makes terminals
## (e.g. Ghostty) render the glyph as a pending/combining char (white highlight).
## Every EAW=Neutral 2-byte option is a living-language letter, an ASCII look-alike,
## or visually noisy. Use -s/--space to pass spaces through literally when tolerable.
